- [Plan a video shot on Hugging Face](https://huggingface.co/spaces/cnblion/freevideoai-shot-planner) with the browser-based static planner.
- [Download three shot exercises](shot-workbook.zip), including a JSON example.
- [Check a portrait animation on DEV](https://dev.to/lion_zhanl_74eb3870e22a92/how-to-check-a-portrait-animation-from-a-single-reference-photo-31lb) against its reference.
