# FreeVideo AI Shot Plan Validator

Open a JSON document containing your video plan and run **FreeVideo AI: Validate Video Shot Plan** from the Command Palette. For example:

    {"mode":"image-to-video","prompt":"Keep the bottle upright as the light moves.","referenceCount":1}

Change the reference count to zero and run the command again to see the validation message. The validator reads the active document locally. Open the [online studio](https://freevideoai.app/ai-video-generator) separately when you want to generate.
